# Introduction

**Linux Kernel Cultivation Chronicle** is a technical novel that explains Linux kernel concepts through the language of cultivation fiction.

The Chinese edition remains the primary source text. This English section provides the i18n structure, navigation, and entry pages so translated content can be added incrementally without moving the existing Chinese routes.

## Reading Path

- Start with the novel overview to understand the story structure.
- Use the reference section when you want a technical map of the kernel concepts.
- Follow source links in chapters to inspect the corresponding Linux code snippets.

## Translation Status

English content is currently a minimal scaffold. New translated chapters can be added under `docs/en/` using the same path shape as the Chinese content when needed.
