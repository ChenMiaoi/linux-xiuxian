# Kernel Map

This page is the English entry point for the technical reference section.

The project explains Linux kernel subsystems through a cultivation metaphor:

| Kernel Area | Story Metaphor |
| --- | --- |
| Boot | Opening heaven and earth |
| Process management | Avatars and lineage |
| Scheduler | Balance and arenas |
| Memory management | Inner world and meridians |
| Filesystems | Eternal forests |
| Networking | Seas and routes |
| Drivers | Bridges between heaven and earth |
| Security | Tribulations and shadows |
| Architecture | Formless Dao |
| Maintainer work | Ascension |

More detailed translated reference pages can be added under `docs/en/reference/`.
