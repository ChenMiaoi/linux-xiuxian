# 简介

欢迎来到 **Linux 内核修仙传**。

这是一部以 Linux 内核为背景的修仙小说。在这个世界里，进程是修士，调度器是天道，内存是内景天地，文件系统是永恒之森。

我们的主角林小源，从最底层的 idle 进程（PID 0）起步，历经九大境界，最终飞升成为内核 Maintainer。

## 本书特色

- **硬核技术**：每个修仙概念都映射真实的内核机制。读完本书，你将对 Linux 内核有深入的理解。
- **修仙叙事**：热血的草根逆袭故事，有师徒、有对手、有天劫、有悟道。
- **源码参悟**：每章附有"道藏笔记"技术解读，可配合 `vendor/linux` 子模块中的真实源码阅读。

## 阅读建议

1. 如果你是内核新手，建议先阅读 [修炼体系](/guide/cultivation-system) 了解境界划分
2. 如果你是修仙老读者，建议先阅读 [世界观设定](/guide/world-building) 了解内核世界
3. 如果你想直接开始冒险，[从第一章开始](/novel/vol1-chaos/ch01)

## 技术参考

本书涉及的内核源码均可在 `vendor/linux` 子模块中找到。每章的"道藏笔记"会标注具体的源码路径和行号。

你也可以访问 [道藏](/reference/kernel-map) 部分，查看完整的内核子系统地图和术语对照表。
