# 第八十五章：文件之形

<CultivationRealm realm="斩灵期" />

> **涉及内核源码：** <KernelSourceLink path="include/linux/fs.h" line="struct file" />

## 一

林小源在森林中看到了一个个"形体"——file 对象。

file 是进程打开文件时创建的对象。它包含读写位置（f_pos）、文件标志（f_flags）、指向 inode 的指针。每个 open() 调用都会创建一个新的 file 对象——即使打开同一个文件。

```c:playground:file — 打开的文件对象
#include <stdio.h>

/*
 * struct file 的关键字段：
 *
 *   f_path — 路径（dentry + vfsmount）
 *   f_inode — 指向的 inode
 *   f_op — 文件操作函数表
 *   f_pos — 当前读写位置
 *   f_flags — 打开标志（O_RDONLY, O_WRONLY...）
 *   f_count — 引用计数
 *
 * file vs inode:
 *   inode — 文件的元数据（一个文件一个）
 *   file — 打开的文件（可以有多个）
 *
 * 一个文件可以被多次打开：
 *   fd1 = open("file", O_RDONLY)  → file1
 *   fd2 = open("file", O_WRONLY)  → file2
 *   两个 file 对象指向同一个 inode
 *
 * fork 后共享 file:
 *   fork() 后，父子进程共享同一个 file
 *   f_pos 是共享的
 */

struct file {
    int fd;
    int inode_no;
    long f_pos;
    int f_flags;
    int f_count;
};

int main() {
    printf("=== file — 打开的文件对象 ===\n\n");

    /* 模拟打开文件 */
    struct file files[4] = {
        {3, 100, 0,    0x0000, 1},  /* O_RDONLY */
        {4, 100, 0,    0x0001, 1},  /* O_WRONLY */
        {5, 200, 1024, 0x0002, 1},  /* O_RDWR, 已读 1024 */
        {6, 100, 512,  0x0000, 2},  /* fork 后共享 */
    };

    printf("打开的文件:\n");
    printf("%-4s %-8s %-8s %-8s %-8s\n",
           "fd", "inode", "pos", "flags", "count");
    printf("%-4s %-8s %-8s %-8s %-8s\n",
           "---", "---", "---", "---", "---");

    for (int i = 0; i < 4; i++) {
        printf("%-4d %-8d %-8ld %-8x %-8d\n",
               files[i].fd, files[i].inode_no,
               files[i].f_pos, files[i].f_flags,
               files[i].f_count);
    }

    printf("\n--- file vs inode ---\n");
    printf("inode:\n");
    printf("  文件的元数据\n");
    printf("  一个文件一个 inode\n");
    printf("  包含权限、大小、数据块位置\n\n");
    printf("file:\n");
    printf("  打开的文件\n");
    printf("  可以有多个 file 指向同一个 inode\n");
    printf("  包含读写位置、打开标志\n\n");

    printf("--- fork 后共享 file ---\n");
    printf("fork() 后:\n");
    printf("  父子进程共享同一个 file 对象\n");
    printf("  f_pos 是共享的\n");
    printf("  父进程读了 100 字节\n");
    printf("  子进程从 100 开始读\n\n");

    printf("--- 文件描述符表 ---\n");
    printf("进程的 fd 表:\n");
    printf("  fd 0 → file (stdin)\n");
    printf("  fd 1 → file (stdout)\n");
    printf("  fd 2 → file (stderr)\n");
    printf("  fd 3 → file (用户打开)\n");

    return 0;
}
```

*原来"形体"是"打开"的化身。*

---

## 二

林小源在研究 file 对象的过程中，理解了它与 fd 的关系。

文件描述符（fd）是进程对 file 对象的"引用"。fd 是一个整数，进程通过 fd 访问 file 对象。多个 fd 可以指向同一个 file（如 fork 后）。

*原来"fd"是"门牌号"。*

---

## 三

林小源在观察 file 对象的过程中，理解了引用计数的作用。

file 有引用计数——fork 后父子进程共享同一个 file，计数为 2。当一个进程关闭 fd 时，计数减 1。当计数降为零时，file 对象被销毁。

*原来"共享"通过"引用计数"管理。*

### 道藏笔记

::: tip 内核启示
**file 是进程打开文件时创建的对象。**

file 的关键字段：
- `f_inode` — 指向的 inode
- `f_pos` — 当前读写位置
- `f_flags` — 打开标志
- `f_count` — 引用计数

file vs inode：
- inode — 文件的元数据，一个文件一个
- file — 打开的文件，可以有多个

fd 与 file 的关系：
- fd 是进程对 file 的引用
- 多个 fd 可以指向同一个 file
- fork 后父子进程共享 file

*file 是"打开"的化身——每次 open() 都会创建一个新的 file。*
:::
