# 第八十二章：守护灵

<CultivationRealm realm="斩灵期" />

> **涉及内核源码：** <KernelSourceLink path="include/linux/fs.h" line="struct super_block" />

## 一

林小源在森林深处，发现了守护灵——superblock。

superblock 是文件系统的"元数据"——它描述整个文件系统的结构：块大小、inode 数量、挂载标志等。没有 superblock，文件系统就无法被识别。

```c:playground:superblock — 文件系统的守护灵
#include <stdio.h>

/*
 * struct super_block 的关键字段：
 *
 *   s_dev — 设备号
 *   s_blocksize — 块大小（通常 4KB）
 *   s_maxbytes — 最大文件大小
 *   s_type — 文件系统类型
 *   s_op — 超级块操作函数表
 *   s_root — 根目录的 dentry
 *   s_inodes — 所有 inode 的链表
 *   s_flags — 挂载标志
 *
 * 超级块操作 (super_operations):
 *   alloc_inode — 分配 inode
 *   destroy_inode — 销毁 inode
 *   write_inode — 写回 inode
 *   evict_inode — 驱逐 inode
 */

struct super_block {
    unsigned long s_dev;
    unsigned long s_blocksize;
    unsigned long long s_maxbytes;
    const char *s_type;
    unsigned long s_flags;
    int s_count;  /* 引用计数 */
};

int main() {
    printf("=== superblock — 文件系统的守护灵 ===\n\n");

    /* 模拟 ext4 的 superblock */
    struct super_block ext4_sb = {
        .s_dev = 0x0801,
        .s_blocksize = 4096,
        .s_maxbytes = 16ULL * 1024 * 1024 * 1024 * 1024,
        .s_type = "ext4",
        .s_flags = 0,
        .s_count = 1,
    };

    printf("ext4 超级块:\n");
    printf("  设备号: 0x%lx\n", ext4_sb.s_dev);
    printf("  块大小: %lu 字节\n", ext4_sb.s_blocksize);
    printf("  最大文件: %llu 字节\n", ext4_sb.s_maxbytes);
    printf("  文件系统类型: %s\n", ext4_sb.s_type);
    printf("  引用计数: %d\n\n", ext4_sb.s_count);

    printf("--- 超级块的生命周期 ---\n");
    printf("1. mount 时读取磁盘上的超级块\n");
    printf("2. 在内存中创建 struct super_block\n");
    printf("3. 文件系统运行期间一直存在\n");
    printf("4. umount 时写回并销毁\n\n");

    printf("--- 超级块操作 ---\n");
    printf("alloc_inode: 分配新的 inode\n");
    printf("destroy_inode: 销毁 inode\n");
    printf("write_inode: 把 inode 写回磁盘\n");
    printf("evict_inode: 从内存中驱逐 inode\n\n");

    printf("--- 超级块 vs 磁盘 ---\n");
    printf("磁盘上的超级块:\n");
    printf("  持久存储\n");
    printf("  包含文件系统的静态信息\n\n");
    printf("内存中的超级块:\n");
    printf("  运行时使用\n");
    printf("  包含额外的运行时信息\n");
    printf("  修改后需要写回磁盘\n");

    return 0;
}
```

*原来"守护灵"是文件系统的"身份证"。*

---

## 二

林小源在研究 superblock 的过程中，理解了它与磁盘的关系。

磁盘上的 superblock 是持久存储的——它包含文件系统的静态信息。内存中的 superblock 是运行时使用的——它包含额外的运行时信息。修改后需要写回磁盘。

*原来"持久"和"运行时"是两个不同的世界。*

---

## 三

林小源在观察 superblock 的过程中，理解了引用计数的作用。

superblock 有引用计数——当计数降为零时，可以销毁。挂载会增加计数，卸载会减少计数。这保证了 superblock 在所有文件都关闭后才被销毁。

*原来"计数"是"生命周期"的管理者。*

### 道藏笔记

::: tip 内核启示
**superblock 是文件系统的元数据。**

superblock 的关键字段：
- `s_blocksize` — 块大小
- `s_maxbytes` — 最大文件大小
- `s_type` — 文件系统类型
- `s_op` — 超级块操作函数表
- `s_root` — 根目录 dentry

超级块操作：
- `alloc_inode` — 分配 inode
- `destroy_inode` — 销毁 inode
- `write_inode` — 写回 inode
- `evict_inode` — 驱逐 inode

磁盘 vs 内存：
- 磁盘 — 持久存储，静态信息
- 内存 — 运行时使用，包含运行时信息

*superblock 是文件系统的"守护灵"——没有它，文件系统无法被识别。*
:::
