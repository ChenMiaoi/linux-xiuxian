# 第一百章：斩灵圆满

<CultivationRealm realm="斩灵圆满" />

## 一

林小源站在文件系统世界的最高处，回望整个旅程。

从最初的 VFS 四大对象，到 ext4、btrfs、procfs、sysfs、tmpfs，再到页缓存、写回、文件锁、fsck——每一步都让他对文件系统有了更深的理解。

*原来"文件系统"是"抽象"的"艺术"。*

---

## 二

林小源在回顾的过程中，理解了文件系统的核心。

VFS 是文件系统的统一抽象——它定义了 superblock、inode、dentry、file 四大对象，让不同的文件系统看起来相同。

*原来"统一"是"力量"的"来源"。*

---

## 三

林小源在总结文件系统的过程中，理解了它的设计哲学。

文件系统的设计处处体现着权衡：
- 性能与安全的权衡（缓存 vs 日志）
- 简单与功能的权衡（ext4 vs btrfs）
- 持久与速度的权衡（磁盘 vs tmpfs）

*原来"设计"是"权衡"的"艺术"。*

---

### 道藏笔记

::: tip 内核启示
**斩灵圆满——文件系统的完整图景。**

文件系统的核心概念：
- VFS — 统一抽象层
- superblock — 文件系统元数据
- inode — 文件元数据
- dentry — 目录项
- file — 打开的文件

文件系统的类型：
- ext4 — 最常用，日志，extent
- btrfs — COW，快照，校验和
- procfs — 内核信息
- sysfs — 设备信息
- tmpfs — 内存文件系统

文件系统的机制：
- 页缓存 — 加速读取
- writeback — 延迟写入
- 文件锁 — 并发控制
- fsck — 检查修复

文件系统的哲学：
- 抽象 — 把复杂变简单
- 分层 — 每层有每层的职责
- 缓存 — 用空间换时间
- 一致性 — 保证数据安全

*文件系统是"树"的艺术——在磁盘上种出目录树。*
:::
