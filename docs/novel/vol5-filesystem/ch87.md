## 一

林小源在森林中发现了一棵巨大的古树——ext4。

ext4 是 Linux 上最常用的文件系统。它是 ext3 的后继者，支持更大的文件、更多的子卷、日志校验等特性。

```c:playground:ext4 — 最常用的文件系统
#include <stdio.h>

/*
 * ext4 的磁盘布局：
 *
 *   Boot Block | Block Group 0 | Block Group 1 | ...
 *
 * 每个 Block Group 包含：
 *   - Superblock（备份）
 *   - Group Descriptors
 *   - Block Bitmap
 *   - Inode Bitmap
 *   - Inode Table
 *   - Data Blocks
 *
 * ext4 的特性：
 *   - 最大文件: 16TB
 *   - 最大文件系统: 1EB
 *   - 日志（JBD2）
 *   - extent（替代间接块）
 *   - 延迟分配
 *   - 多块分配
 */

int main() {
    printf("=== ext4 — 最常用的文件系统 ===\n\n");

    printf("ext4 磁盘布局:\n");
    printf("  ┌─────────────────────────────────────┐\n");
    printf("  │ Boot Block (1KB)                    │\n");
    printf("  ├─────────────────────────────────────┤\n");
    printf("  │ Block Group 0                       │\n");
    printf("  │  ├── Superblock                     │\n");
    printf("  │  ├── Group Descriptors              │\n");
    printf("  │  ├── Block Bitmap                   │\n");
    printf("  │  ├── Inode Bitmap                   │\n");
    printf("  │  ├── Inode Table                    │\n");
    printf("  │  └── Data Blocks                    │\n");
    printf("  ├─────────────────────────────────────┤\n");
    printf("  │ Block Group 1                       │\n");
    printf("  │  └── ...                            │\n");
    printf("  └─────────────────────────────────────┘\n\n");

    printf("--- ext4 的特性 ---\n");
    printf("1. extent\n");
    printf("   替代传统的间接块\n");
    printf("   一个 extent 描述连续的数据块\n");
    printf("   减少元数据开销\n\n");
    printf("2. 延迟分配\n");
    printf("   写入时不立即分配磁盘块\n");
    printf("   等到写回时再分配\n");
    printf("   减少碎片\n\n");
    printf("3. 日志（JBD2）\n");
    printf("   记录元数据操作\n");
    printf("   崩溃后快速恢复\n\n");
    printf("4. 多块分配\n");
    printf("   一次分配多个连续块\n");
    printf("   提高大文件性能\n\n");

    printf("--- inode 结构 ---\n");
    printf("传统 ext2/3 inode:\n");
    printf("  12 个直接块指针\n");
    printf("  1 个间接块指针\n");
    printf("  1 个二级间接块指针\n");
    printf("  1 个三级间接块指针\n\n");
    printf("ext4 inode:\n");
    printf("  使用 extent tree\n");
    printf("  每个 extent 描述连续块\n");
    printf("  更高效\n\n");

    printf("--- ext4 vs ext3 ---\n");
    printf("ext3: 最大 2TB 文件, 16TB 文件系统\n");
    printf("ext4: 最大 16TB 文件, 1EB 文件系统\n");
    printf("ext4: extent, 延迟分配, 日志校验\n");

    return 0;
}
```

*原来"古树"的"年轮"是 block group。*

---

## 二

林小源在研究 ext4 的过程中，理解了 extent 的优势。

传统的间接块机制需要多次磁盘访问才能找到数据块。extent 用一个结构描述连续的数据块——减少了元数据开销，提高了大文件的性能。

*原来"连续"比"分散"更高效。*

---

## 三

林小源在观察 ext4 的过程中，理解了延迟分配的智慧。

写入时不立即分配磁盘块——等到写回时再分配。这样内核可以更好地了解数据的大小和位置，分配更连续的块，减少碎片。

*原来"延迟"是一种"优化"。*

### 道藏笔记

::: tip 内核启示
**ext4 是 Linux 最常用的文件系统。**

ext4 的磁盘布局：
- Boot Block
- Block Group（包含 superblock、bitmap、inode table、data blocks）

ext4 的特性：
- extent — 替代间接块，描述连续数据块
- 延迟分配 — 写回时再分配磁盘块
- 日志（JBD2）— 崩溃后快速恢复
- 多块分配 — 一次分配多个连续块

ext4 vs ext3：
- 更大的文件和文件系统
- extent 替代间接块
- 延迟分配减少碎片

*ext4 是"古老"但"强大"的文件系统——经过多年的打磨。*
:::
