# 第九十一章：procfs

<CultivationRealm realm="斩灵期" />

> **涉及内核源码：** <KernelSourceLink path="fs/proc/base.c" />

## 一

林小源在森林中发现了一棵特殊的树——procfs。

procfs 不是真正的文件系统——它不存储文件。它是内核向用户空间暴露信息的接口。通过读取 `/proc` 下的文件，用户可以查看进程信息、内核参数、硬件信息等。

```c:playground:procfs — 内核的信息窗口
#include <stdio.h>

/*
 * procfs 的结构：
 *
 *   /proc/
 *   ├── [pid]/           — 进程信息
 *   │   ├── status       — 进程状态
 *   │   ├── maps         — 内存映射
 *   │   ├── fd/          — 打开的文件描述符
 *   │   └── cmdline      — 命令行参数
 *   ├── cpuinfo          — CPU 信息
 *   ├── meminfo          — 内存信息
 *   ├── mounts           — 挂载信息
 *   ├── version          — 内核版本
 *   └── sys/             — 内核参数
 *
 * procfs 的特点：
 *   - 不占用磁盘空间
 *   - 内核动态生成内容
 *   - 可以通过写入修改内核参数
 */

int main() {
    printf("=== procfs — 内核的信息窗口 ===\n\n");

    printf("procfs 目录结构:\n");
    printf("  /proc/\n");
    printf("  ├── [pid]/           进程信息\n");
    printf("  │   ├── status       进程状态\n");
    printf("  │   ├── maps         内存映射\n");
    printf("  │   ├── fd/          文件描述符\n");
    printf("  │   └── cmdline      命令行参数\n");
    printf("  ├── cpuinfo          CPU 信息\n");
    printf("  ├── meminfo          内存信息\n");
    printf("  ├── mounts           挂载信息\n");
    printf("  ├── version          内核版本\n");
    printf("  └── sys/             内核参数\n\n");

    printf("--- 进程信息 ---\n");
    printf("/proc/[pid]/status:\n");
    printf("  Name: bash\n");
    printf("  State: S (sleeping)\n");
    printf("  Pid: 1234\n");
    printf("  PPid: 1\n");
    printf("  VmSize: 12345 kB\n\n");

    printf("/proc/[pid]/maps:\n");
    printf("  7f0000000-7f0010000 r-xp /lib/libc.so\n");
    printf("  7fff00000-7fff002000 rw-p [stack]\n\n");

    printf("--- 系统信息 ---\n");
    printf("/proc/cpuinfo:\n");
    printf("  processor: 0\n");
    printf("  model name: Intel Core i7\n");
    printf("  cpu MHz: 3000.000\n\n");

    printf("/proc/meminfo:\n");
    printf("  MemTotal: 16384000 kB\n");
    printf("  MemFree: 8192000 kB\n");
    printf("  MemAvailable: 12288000 kB\n\n");

    printf("--- 内核参数 ---\n");
    printf("/proc/sys/:\n");
    printf("  kernel/hostname\n");
    printf("  net/ipv4/ip_forward\n");
    printf("  vm/swappiness\n\n");
    printf("修改内核参数:\n");
    printf("  echo 1 > /proc/sys/net/ipv4/ip_forward\n");
    printf("  sysctl -w kernel.hostname=myhost\n");

    return 0;
}
```

*原来"窗口"可以"透视"内核。*

---

## 二

林小源在研究 procfs 的过程中，理解了它的实现原理。

procfs 中的文件不是真正的文件——它们是内核中的函数。当用户读取 `/proc/cpuinfo` 时，内核调用对应的函数，动态生成内容返回给用户。

*原来"文件"是"函数"的"伪装"。*

---

## 三

林小源在观察 procfs 的过程中，理解了它的双向通信能力。

procfs 不仅可以读取内核信息，还可以通过写入修改内核参数。`/proc/sys/` 下的文件对应 `sysctl` 参数——写入新值可以改变内核行为。

*原来"窗口"是"双向"的。*

::: tip 内核启示
**procfs 是内核向用户空间暴露信息的接口。**

procfs 的结构：
- `/proc/[pid]/` — 进程信息
- `/proc/cpuinfo` — CPU 信息
- `/proc/meminfo` — 内存信息
- `/proc/sys/` — 内核参数

procfs 的特点：
- 不占用磁盘空间
- 内核动态生成内容
- 可以通过写入修改参数

procfs 的实现：
- 文件对应内核中的函数
- 读取时动态生成内容
- 写入时修改内核状态

*procfs 是"窗口"——让内核和用户空间对话。*
