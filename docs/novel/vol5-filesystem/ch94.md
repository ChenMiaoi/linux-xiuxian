# 第九十四章：页缓存

<CultivationRealm realm="斩灵期" />

> **涉及内核源码：** <KernelSourceLink path="mm/filemap.c" line="generic_file_read_iter" />

## 一

林小源在研究文件系统的过程中，发现了一个关键机制：页缓存（Page Cache）。

页缓存是内存中缓存文件数据的区域。当读取文件时，内核先检查页缓存——如果数据在缓存中，直接返回；否则从磁盘读取并缓存。

```c:playground:页缓存 — 文件数据的内存缓存
#include <stdio.h>

/*
 * 页缓存的工作原理：
 *
 * 1. 读取文件
 *    先检查页缓存
 *    命中: 直接返回（快）
 *    未命中: 从磁盘读取，缓存后返回（慢）
 *
 * 2. 写入文件
 *    写入页缓存（快）
 *    标记为"脏页"
 *    后续由 writeback 写入磁盘
 *
 * 3. 缓存淘汰
 *    内存不足时，淘汰不活跃的页面
 *    LRU 算法
 *
 * 页缓存的好处：
 *   - 减少磁盘 I/O
 *   - 加速读取
 *   - 合并写入
 *
 * 页缓存的组织：
 *   address_space 结构
 *   每个 inode 有一个 address_space
 *   用 radix tree (xarray) 组织
 */

int main() {
    printf("=== 页缓存 — 文件数据的内存缓存 ===\n\n");

    printf("页缓存的工作原理:\n\n");

    printf("1. 读取文件:\n");
    printf("   进程: read(fd, buf, size)\n");
    printf("   内核: 检查页缓存\n");
    printf("   命中: 直接返回（快）\n");
    printf("   未命中: 磁盘读取 → 缓存 → 返回（慢）\n\n");

    printf("2. 写入文件:\n");
    printf("   进程: write(fd, buf, size)\n");
    printf("   内核: 写入页缓存（快）\n");
    printf("   标记为"脏页"\n");
    printf("   后续: writeback 写入磁盘\n\n");

    printf("--- 页缓存的结构 ---\n");
    printf("address_space:\n");
    printf("  每个 inode 有一个\n");
    printf("  用 xarray 组织页面\n");
    printf("  页面按文件偏移索引\n\n");

    printf("xarray (radix tree):\n");
    printf("  [0] → page (偏移 0-4KB)\n");
    printf("  [1] → page (偏移 4KB-8KB)\n");
    printf("  [2] → NULL (未缓存)\n");
    printf("  [3] → page (偏移 12KB-16KB)\n\n");

    printf("--- 缓存命中率 ---\n");
    printf("命中率 = 缓存命中次数 / 总访问次数\n\n");
    printf("高命中率:\n");
    printf("  大部分访问在缓存中\n");
    printf("  性能好\n\n");
    printf("低命中率:\n");
    printf("  大部分访问需要磁盘 I/O\n");
    printf("  性能差\n\n");

    printf("--- 查看页缓存 ---\n");
    printf("free -h:\n");
    printf("  buff/cache: 2.1G\n\n");
    printf("vmstat 1:\n");
    printf("  bi: 块设备读入\n");
    printf("  bo: 块设备写出\n\n");
    printf("/proc/meminfo:\n");
    printf("  Cached: 2145678 kB\n");

    return 0;
}
```

*原来"缓存"是"速度"的"秘密"。*

## 二

林小源在研究页缓存的过程中，理解了读取的优化。

当进程读取文件时，内核不是读取请求的字节数——而是读取整个页面（4KB）。这样，如果进程继续读取相邻的数据，可以直接从缓存中获取。

*原来"预读"是"优化"的方式。*

---

## 三

林小源在观察页缓存的过程中，理解了它与内存管理的关系。

页缓存占用物理内存——当内存不足时，内核会淘汰不活跃的缓存页面。这就是为什么 `free` 命令显示的"空闲"内存可能很少——大部分被页缓存占用了。

*原来"空闲"不等于"可用"。*

### 道藏笔记

::: tip 内核启示
**页缓存是文件数据的内存缓存。**

页缓存的工作原理：
- 读取：先检查缓存，命中则直接返回
- 写入：写入缓存，标记为脏页
- 写回：脏页由 writeback 写入磁盘

页缓存的组织：
- 每个 inode 有一个 address_space
- 用 xarray（radix tree）组织页面
- 页面按文件偏移索引

页缓存的好处：
- 减少磁盘 I/O
- 加速读取
- 合并写入

*页缓存是"速度"的秘密——让磁盘访问变成内存访问。*
:::
