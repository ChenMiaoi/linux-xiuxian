# 第九十三章：tmpfs

<CultivationRealm realm="斩灵期" />

## 一

林小源在森林中发现了一棵"虚幻"的树——tmpfs。

tmpfs 是基于内存的文件系统——它不占用磁盘空间，只使用 RAM 和 swap。重启后所有数据丢失。`/tmp`、`/run` 通常使用 tmpfs。

```c:playground:tmpfs — 内存文件系统
#include <stdio.h>

/*
 * tmpfs 的特点：
 *
 * 1. 基于内存
 *    数据存储在 RAM 中
 *    可以使用 swap
 *    重启后丢失
 *
 * 2. 动态大小
 *    不需要预先分配大小
 *    随使用量增长
 *    受限于 RAM + swap
 *
 * 3. 快速访问
 *    没有磁盘 I/O
 *    读写速度 = 内存速度
 *
 * 4. 支持所有文件操作
 *    创建、删除、读写
 *    权限、所有者
 *
 * tmpfs 的用途：
 *   /tmp — 临时文件
 *   /run — 运行时数据
 *   /dev/shm — 共享内存
 *   /sys/fs/cgroup — cgroup 文件系统
 *
 * 挂载 tmpfs:
 *   mount -t tmpfs tmpfs /tmp
 *   mount -t tmpfs -o size=1G tmpfs /tmp
 */

int main() {
    printf("=== tmpfs — 内存文件系统 ===\n\n");

    printf("tmpfs 的特点:\n");
    printf("  基于内存: 数据在 RAM 中\n");
    printf("  动态大小: 随使用量增长\n");
    printf("  快速访问: 内存速度\n");
    printf("  易失性: 重启后丢失\n\n");

    printf("--- tmpfs 的用途 ---\n");
    printf("/tmp:\n");
    printf("  临时文件\n");
    printf("  程序运行时创建\n");
    printf("  重启后清理\n\n");
    printf("/run:\n");
    printf("  运行时数据\n");
    printf("  PID 文件\n");
    printf("  socket 文件\n\n");
    printf("/dev/shm:\n");
    printf("  POSIX 共享内存\n");
    printf("  进程间通信\n\n");

    printf("--- tmpfs vs ramfs ---\n");
    printf("ramfs:\n");
    printf("  基于内存\n");
    printf("  不能使用 swap\n");
    printf("  可以无限增长（危险）\n\n");
    printf("tmpfs:\n");
    printf("  基于内存\n");
    printf("  可以使用 swap\n");
    printf("  有大小限制\n\n");

    printf("--- 挂载选项 ---\n");
    printf("mount -t tmpfs -o size=1G,nr_inodes=100k tmpfs /tmp\n");
    printf("  size: 最大大小\n");
    printf("  nr_inodes: 最大 inode 数\n\n");

    printf("--- tmpfs 的优势 ---\n");
    printf("1. 速度: 内存速度访问\n");
    printf("2. 简单: 不需要磁盘分区\n");
    printf("3. 灵活: 动态大小\n");
    printf("4. 清洁: 重启后自动清理\n");

    return 0;
}
```

*原来"虚幻"的树也有"真实"的用途。*

## 二

林小源在研究 tmpfs 的过程中，理解了它与磁盘文件系统的区别。

磁盘文件系统的数据持久存储在磁盘上——重启后还在。tmpfs 的数据只在内存中——重启后丢失。但 tmpfs 的访问速度比磁盘快得多。

*原来"持久"和"速度"是矛盾的。*

---

## 三

林小源在观察 tmpfs 的过程中，理解了 `/dev/shm` 的作用。

`/dev/shm` 是 tmpfs 的一个挂载点——它用于 POSIX 共享内存。多个进程可以通过读写 `/dev/shm` 下的文件进行通信，速度比磁盘文件系统快得多。

*原来"共享内存"也是"文件"。*

### 道藏笔记

::: tip 内核启示
**tmpfs 是基于内存的文件系统。**

tmpfs 的特点：
- 基于内存（RAM + swap）
- 动态大小
- 快速访问
- 重启后丢失

tmpfs 的用途：
- `/tmp` — 临时文件
- `/run` — 运行时数据
- `/dev/shm` — POSIX 共享内存

tmpfs vs ramfs：
- ramfs — 不能使用 swap，可无限增长
- tmpfs — 可以使用 swap，有大小限制

*tmpfs 是"虚幻"的——但它的速度是"真实"的。*
:::
