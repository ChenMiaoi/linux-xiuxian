# 第五卷：永恒之森

> **修炼阶段：** <CultivationRealm realm="斩灵期" />
> **内核焦点：** 文件系统 (`fs/`, VFS)

## 卷首语

斩去对具象的执着，方能领悟抽象的真谛。

VFS 是至高的抽象大道——无论 ext4、btrfs 还是 procfs，在它面前皆为一。inode 是古树，dentry 是路标，superblock 是森林的守护灵。

但当文件系统腐朽之时，唯有 fsck 净化仪式方能拯救一切。
