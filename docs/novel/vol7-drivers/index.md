# 第七卷：天地之桥

> **修炼阶段：** <CultivationRealm realm="合道期" />
> **内核焦点：** 设备驱动 (`drivers/`)

## 卷首语

天地之间，有桥相连。

设备山脉是内核界与硬件界的屏障。驱动修士是沟通两界的使者——他们用 DMA 传递灵魂能量，用中断监听天地的呼唤，用 PCI 枚举发现深藏的宝藏。

但硬件中的恶灵（硬件 bug）也在蠢蠢欲动。
