# 第一百四十四章：USB

<CultivationRealm realm="合道期" />

> **涉及内核源码：** <KernelSourceLink path="drivers/usb/core/driver.c" />

## 一

林小源在设备山脉中发现了最常见的接口——USB。

USB（Universal Serial Bus）是通用的串行总线——键盘、鼠标、U盘、摄像头都通过 USB 连接。

```c:playground:USB — 通用串行总线
#include <stdio.h>

/*
 * USB 的特点:
 *
 *   通用: 支持多种设备
 *   热插拔: 支持动态连接
 *   供电: 可以为设备供电
 *   速度: USB 2.0 (480Mbps), USB 3.0 (5Gbps)
 *
 * USB 驱动:
 *   struct usb_driver:
 *     probe — 初始化
 *     disconnect — 断开
 *     id_table — 匹配表
 *
 * USB 通信:
 *   usb_control_msg — 控制传输
 *   usb_bulk_msg — 批量传输
 *   usb_interrupt_msg — 中断传输
 *
 * USB 设备描述符:
 *   设备描述符 → 配置描述符 → 接口描述符 → 端点描述符
 */

int main() {
    printf("=== USB — 通用串行总线 ===\n\n");

    printf("USB 的特点:\n");
    printf("  通用: 支持多种设备\n");
    printf("  热插拔: 动态连接\n");
    printf("  供电: 为设备供电\n");
    printf("  速度: USB 2.0 (480Mbps)\n\n");

    printf("--- USB 驱动 ---\n");
    printf("struct usb_driver my_drv = {\n");
    printf("  .name = \"my_usb\",\n");
    printf("  .probe = my_probe,\n");
    printf("  .disconnect = my_disconnect,\n");
    printf("  .id_table = my_ids,\n");
    printf("};\n\n");

    printf("--- USB 传输类型 ---\n");
    printf("控制传输:\n");
    printf("  配置设备\n");
    printf("  usb_control_msg()\n\n");
    printf("批量传输:\n");
    printf("  大量数据\n");
    printf("  U盘、打印机\n\n");
    printf("中断传输:\n");
    printf("  定期轮询\n");
    printf("  键盘、鼠标\n\n");
    printf("等时传输:\n");
    printf("  实时数据\n");
    printf("  音频、视频\n\n");

    printf("--- USB 设备描述符 ---\n");
    printf("设备描述符:\n");
    printf("  厂商 ID、产品 ID\n\n");
    printf("配置描述符:\n");
    printf("  设备的配置信息\n\n");
    printf("接口描述符:\n");
    printf("  设备的功能接口\n\n");
    printf("端点描述符:\n");
    printf("  数据传输的端点\n\n");

    printf("--- lsusb ---\n");
    printf("lsusb 命令查看 USB 设备:\n");
    printf("  Bus 001 Device 003:\n");
    printf("    ID 046d:c077 Logitech Mouse\n");

    return 0;
}
```

*原来"USB"是"万能"的"接口"。*

---

## 二

林小源在研究 USB 的过程中，理解了热插拔的机制。

USB 支持热插拔——设备可以在系统运行时连接和断开。内核会自动检测设备变化，加载或卸载驱动。

*原来"热插拔"是"动态"的"管理"。*

---

## 三

林小源在观察 USB 的过程中，理解了描述符的层次结构。

USB 设备通过描述符描述自己——设备描述符包含配置，配置描述符包含接口，接口描述符包含端点。这种层次结构让一个设备可以有多种功能。

*原来"层次"是"组织"的"方式"。*

- 控制传输 — 配置设备
- 批量传输 — 大量数据
- 中断传输 — 定期轮询
- 等时传输 — 实时数据

*USB 是"万能"的接口——连接各种设备。*
