# 第一百四十二章：I2C

<CultivationRealm realm="合道期" />

> **涉及内核源码：** <KernelSourceLink path="drivers/i2c/i2c-core-base.c" />

## 一

林小源在设备山脉中发现了一种低速总线——I2C。

I2C（Inter-Integrated Circuit）是连接低速设备的串行总线——传感器、EEPROM、RTC 等。它只需要两根线（SDA、SCL），简单而高效。

```c:playground:I2C — 低速串行总线
#include <stdio.h>

/*
 * I2C 的特点:
 *
 *   两根线: SDA (数据) + SCL (时钟)
 *   主从模式: 主机发起通信
 *   地址寻址: 每个设备有唯一地址
 *   速度: 100K/400K/3.4M
 *
 * I2C 驱动:
 *   struct i2c_driver:
 *     probe — 初始化
 *     remove — 移除
 *     id_table — 匹配表
 *
 * I2C 通信:
 *   i2c_master_send — 发送数据
 *   i2c_master_recv — 接收数据
 *   i2c_transfer — 传输消息
 *
 * 设备树描述:
 *   sensor@48 {
 *     compatible = "vendor,sensor";
 *     reg = <0x48>;
 *   };
 */

int main() {
    printf("=== I2C — 低速串行总线 ===\n\n");

    printf("I2C 的特点:\n");
    printf("  两根线: SDA + SCL\n");
    printf("  主从模式\n");
    printf("  地址寻址\n");
    printf("  速度: 100K/400K/3.4M\n\n");

    printf("--- I2C 驱动 ---\n");
    printf("struct i2c_driver my_drv = {\n");
    printf("  .probe = my_probe,\n");
    printf("  .remove = my_remove,\n");
    printf("  .id_table = my_ids,\n");
    printf("  .driver = {\n");
    printf("    .name = \"my_sensor\",\n");
    printf("    .of_match_table = my_of_ids,\n");
    printf("  },\n");
    printf("};\n\n");

    printf("--- I2C 通信 ---\n");
    printf("发送数据:\n");
    printf("  i2c_master_send(client, buf, len)\n\n");
    printf("接收数据:\n");
    printf("  i2c_master_recv(client, buf, len)\n\n");
    printf("传输消息:\n");
    printf("  i2c_transfer(adapter, msgs, num)\n\n");

    printf("--- 设备树描述 ---\n");
    printf("sensor@48 {\n");
    printf("  compatible = \"vendor,sensor\";\n");
    printf("  reg = <0x48>;  // I2C 地址\n");
    printf("};\n\n");

    printf("--- I2C 设备 ---\n");
    printf("传感器: 温度、湿度、加速度\n");
    printf("EEPROM: 小容量存储\n");
    printf("RTC: 实时时钟\n");
    printf("显示屏: OLED、LCD\n");

    return 0;
}
```

*原来"I2C"是"简单"的"总线"。*

## 二

林小源在研究 I2C 的过程中，理解了地址寻址的机制。

I2C 总线上的每个设备有唯一的地址——主机通过地址选择要通信的设备。地址通常是 7 位，范围 0x03-0x77。

*原来"地址"是"选择"的"方式"。*

---

## 三

林小源在观察 I2C 的过程中，理解了它的适用场景。

I2C 适合低速、短距离的通信——传感器、EEPROM 等。它只需要两根线，节省引脚，但速度不如 SPI。

*原来"简单"有"限制"。*
