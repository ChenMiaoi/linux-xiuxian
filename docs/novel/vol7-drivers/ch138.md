# 第一百三十八章：设备模型

<CultivationRealm realm="合道期" />

> **涉及内核源码：** <KernelSourceLink path="drivers/base/core.c" line="device_register" />

## 一

林小源在设备山脉中发现了设备管理的核心——设备模型。

设备模型是内核管理设备的框架——它用 kobject、kset、device 等结构组织设备，并通过 sysfs 暴露给用户空间。

```c:playground:设备模型 — 设备管理的框架
#include <stdio.h>

/*
 * 设备模型的核心结构:
 *
 * kobject:
 *   内核对象的基类
 *   引用计数、sysfs 表示
 *   嵌入在其他结构中
 *
 * kset:
 *   kobject 的集合
 *   对应 sysfs 中的目录
 *
 * device:
 *   设备的抽象
 *   包含 kobject
 *   关联驱动、总线
 *
 * device_driver:
 *   驱动的抽象
 *   包含操作函数
 *
 * bus_type:
 *   总线类型
 *   管理设备和驱动的匹配
 */

int main() {
    printf("=== 设备模型 — 设备管理的框架 ===\n\n");

    printf("设备模型的核心结构:\n\n");

    printf("kobject:\n");
    printf("  内核对象的基类\n");
    printf("  引用计数\n");
    printf("  sysfs 表示\n\n");

    printf("kset:\n");
    printf("  kobject 的集合\n");
    printf("  对应 sysfs 目录\n\n");

    printf("device:\n");
    printf("  设备的抽象\n");
    printf("  包含 kobject\n");
    printf("  关联驱动、总线\n\n");

    printf("--- 层次结构 ---\n");
    printf("  bus_type\n");
    printf("  ├── device 1\n");
    printf("  │   └── kobject\n");
    printf("  ├── device 2\n");
    printf("  │   └── kobject\n");
    printf("  └── device_driver\n\n");

    printf("--- sysfs 对应 ---\n");
    printf("/sys/\n");
    printf("├── bus/\n");
    printf("│   ├── pci/\n");
    printf("│   └── usb/\n");
    printf("├── devices/\n");
    printf("│   └── pci0000:00/\n");
    printf("└── class/\n");
    printf("    └── net/\n\n");

    printf("--- 设备注册 ---\n");
    printf("device_register(&dev):\n");
    printf("  注册设备\n");
    printf("  创建 sysfs 条目\n");
    printf("  尝试匹配驱动\n\n");

    printf("--- 驱动注册 ---\n");
    printf("driver_register(&drv):\n");
    printf("  注册驱动\n");
    printf("  尝试匹配设备\n");

    return 0;
}
```

*原来"设备模型"是"组织"的"框架"。*

---

## 二

林小源在研究设备模型的过程中，理解了 kobject 的核心作用。

kobject 是所有内核对象的基类——它提供引用计数和 sysfs 表示。device、driver 等结构都嵌入了 kobject。

*原来"kobject"是"基础"的"基础"。*

---

## 三

林小源在观察设备模型的过程中，理解了总线-设备-驱动的关系。

总线管理设备和驱动的匹配——当新设备注册时，总线找到匹配的驱动；当新驱动注册时，总线找到匹配的设备。

*原来"匹配"是"总线"的"职责"。*

### 道藏笔记

::: tip 内核启示
**设备模型是内核管理设备的框架。**

核心结构：
- kobject — 内核对象基类
- kset — kobject 集合
- device — 设备抽象
- device_driver — 驱动抽象
- bus_type — 总线类型

总线-设备-驱动关系：
- 总线管理匹配
- 设备注册时匹配驱动
- 驱动注册时匹配设备

*设备模型是"组织"的框架——让设备管理有序。*
:::
