## 一

林小源在设备山脉中发现了调试驱动的工具和技巧。

驱动调试比用户空间程序更难——错误可能导致系统崩溃。内核提供了多种调试工具。

```c:playground:设备调试 — 找到隐藏的 bug
#include <stdio.h>

/*
 * 驱动调试工具:
 *
 * 1. printk
 *    内核日志
 *    不同级别: KERN_INFO, KERN_ERR
 *
 * 2. dev_dbg/dev_err
 *    设备相关的日志
 *    包含设备名
 *
 * 3. ftrace
 *    函数跟踪
 *    跟踪函数调用
 *
 * 4. kprobes
 *    动态探针
 *    在任意函数上设置断点
 *
 * 5. /sys/kernel/debug/
 *    调试文件系统
 *    驱动可以注册调试信息
 *
 * 常见驱动 bug:
 *   竞态条件
 *   内存泄漏
 *   中断处理不当
 *   DMA 一致性问题
 */

int main() {
    printf("=== 设备调试 — 找到隐藏的 bug ===\n\n");

    printf("驱动调试工具:\n\n");

    printf("1. printk:\n");
    printf("   内核日志\n");
    printf("   printk(KERN_INFO \"msg\\n\");\n\n");

    printf("2. dev_dbg/dev_err:\n");
    printf("   设备相关的日志\n");
    printf("   dev_err(&pdev->dev, \"error\\n\");\n\n");

    printf("3. ftrace:\n");
    printf("   函数跟踪\n");
    printf("   跟踪函数调用\n\n");

    printf("4. kprobes:\n");
    printf("   动态探针\n");
    printf("   在任意函数上设置断点\n\n");

    printf("5. debugfs:\n");
    printf("   /sys/kernel/debug/\n");
    printf("   驱动注册调试信息\n\n");

    printf("--- 常见驱动 bug ---\n");
    printf("竞态条件:\n");
    printf("  多个线程同时访问\n");
    printf("  需要加锁\n\n");
    printf("内存泄漏:\n");
    printf("  分配了没有释放\n\n");
    printf("中断处理不当:\n");
    printf("  处理时间太长\n");
    printf("  没有清除中断标志\n\n");
    printf("DMA 一致性:\n");
    printf("  缓存没有刷新\n\n");

    printf("--- 调试技巧 ---\n");
    printf("1. 使用 printk 跟踪执行路径\n");
    printf("2. 检查错误返回值\n");
    printf("3. 使用 lockdep 检测死锁\n");
    printf("4. 使用 KASAN 检测内存错误\n");

    return 0;
}
```

*原来"调试"是"发现"的"艺术"。*

## 二

林小源在研究设备调试的过程中，理解了 printk 的重要性。

printk 是内核最基本的调试工具——它输出日志到内核日志缓冲区。不同的日志级别控制消息的显示。

*原来"printk"是"调试"的"基础"。*

---

## 三

林小源在观察设备调试的过程中，理解了 ftrace 的强大。

ftrace 可以跟踪内核函数的调用——帮助理解代码的执行路径。它是分析性能和调试问题的利器。

*原来"ftrace"是"分析"的"利器"。*

---

### 道藏笔记

::: tip 内核启示
**驱动调试需要专门的工具和技巧。**

调试工具：
- `printk` — 内核日志
- `dev_dbg/dev_err` — 设备日志
- `ftrace` — 函数跟踪
- `kprobes` — 动态探针
- `debugfs` — 调试文件系统

常见驱动 bug：
- 竞态条件
- 内存泄漏
- 中断处理不当
- DMA 一致性

*调试是"发现"的艺术——让隐藏的 bug 无处遁形。*
:::
