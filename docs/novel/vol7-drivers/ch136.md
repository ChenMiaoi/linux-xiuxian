# 第一百三十六章：中断下半部

<CultivationRealm realm="合道期" />

> **涉及内核源码：** <KernelSourceLink path="kernel/softirq.c" />

## 一

林小源在研究中断的过程中，发现了一个设计模式：中断上下半部。

上半部（硬中断）处理紧急的工作——读取设备状态、清除中断标志。下半部处理耗时的工作——数据处理、协议栈逻辑。

```c:playground:中断下半部 — 延迟处理
#include <stdio.h>

/*
 * 中断下半部的机制:
 *
 * 1. softirq (软中断)
 *    静态定义，编译时确定
 *    类型有限（约 10 种）
 *    性能最好
 *    例: NET_RX_SOFTIRQ, TIMER_SOFTIRQ
 *
 * 2. tasklet
 *    基于 softirq 实现
 *    可以动态创建
 *    使用更简单
 *    同一 tasklet 不能并发
 *
 * 3. 工作队列
 *    在进程上下文中执行
 *    可以休眠
 *    最灵活
 *
 * 选择:
 *   需要最高性能 → softirq
 *   简单延迟处理 → tasklet
 *   需要休眠 → 工作队列
 */

int main() {
    printf("=== 中断下半部 — 延迟处理 ===\n\n");

    printf("中断上下半部:\n\n");
    printf("上半部 (硬中断):\n");
    printf("  处理紧急工作\n");
    printf("  读取设备状态\n");
    printf("  清除中断标志\n");
    printf("  调度下半部\n\n");
    printf("下半部:\n");
    printf("  处理耗时工作\n");
    printf("  数据处理\n");
    printf("  协议栈逻辑\n\n");

    printf("--- 下半部机制 ---\n\n");

    printf("1. softirq:\n");
    printf("   静态定义\n");
    printf("   性能最好\n");
    printf("   NET_RX_SOFTIRQ — 网络收包\n");
    printf("   TIMER_SOFTIRQ — 定时器\n\n");

    printf("2. tasklet:\n");
    printf("   基于 softirq\n");
    printf("   可以动态创建\n");
    printf("   同一 tasklet 不能并发\n\n");

    printf("3. 工作队列:\n");
    printf("   在进程上下文中执行\n");
    printf("   可以休眠\n");
    printf("   最灵活\n\n");

    printf("--- 选择 ---\n");
    printf("需要最高性能 → softirq\n");
    printf("简单延迟处理 → tasklet\n");
    printf("需要休眠 → 工作队列\n\n");

    printf("--- 网络中断示例 ---\n");
    printf("上半部:\n");
    printf("  网卡中断\n");
    printf("  读取状态\n");
    printf("  调度 NET_RX_SOFTIRQ\n\n");
    printf("下半部:\n");
    printf("  处理收到的数据包\n");
    printf("  传递给协议栈\n");

    return 0;
}
```

*原来"下半部"是"延迟"的"处理"。*

---

## 二

林小源在研究中断下半部的过程中，理解了 softirq 的高性能。

softirq 是静态定义的——类型在编译时确定。这减少了运行时开销，但灵活性不如 tasklet 和工作队列。

*原来"静态"是"快速"的"来源"。*

---

## 三

林小源在观察中断下半部的过程中，理解了工作队列的灵活性。

工作队列在进程上下文中执行——可以休眠、可以获取锁。它适合需要做复杂处理（如内存分配、文件操作）的场景。

*原来"进程上下文"是"灵活"的"保障"。*

---

### 道藏笔记

::: tip 内核启示
**中断下半部处理耗时的工作。**

下半部机制：
- softirq — 静态定义，性能最好
- tasklet — 动态创建，使用简单
- 工作队列 — 进程上下文，可以休眠

选择原则：
- 最高性能 → softirq
- 简单延迟 → tasklet
- 需要休眠 → 工作队列

*下半部是"延迟"的智慧——把耗时的工作留到后面。*
:::
