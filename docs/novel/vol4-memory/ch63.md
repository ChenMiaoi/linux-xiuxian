# 第六十三章：匿名之页

<CultivationRealm realm="元婴中期" />

> **涉及内核源码：** <KernelSourceLink path="mm/memory.c" line="do_anonymous_page" />

## 一

林小源在研究内存管理的过程中，发现了两种页面：匿名页和文件页。

匿名页——没有关联任何文件的页面。堆、栈、`mmap` 匿名映射——这些都是匿名页。

```c:playground:匿名页 — 无名之页
#include <stdio.h>

/*
 * 匿名页的特点：
 * 1. 没有关联文件
 * 2. 内容全零（首次访问时）
 * 3. 不能从文件恢复（需要 swap）
 * 4. 使用 anon_vma 管理
 *
 * 匿名页的分配：
 *   do_anonymous_page()
 *   1. 分配一个新的物理页
 *   2. 清零
 *   3. 更新页表
 *   4. 返回
 *
 * 零页 (zero page)：
 *   一个特殊的全局物理页，内容全零
 *   所有只读的匿名页都映射到零页
 *   只有在写入时才分配真正的物理页（COW）
 */

struct page {
    int refcount;
    int mapcount;       /* 映射计数 */
    unsigned long flags;
    char data[64];
};

#define PG_anonymous  (1 << 0)
#define PG_swapcache  (1 << 1)
#define PG_lru        (1 << 2)

int main() {
    printf("=== 匿名页 — 无名之页 ===\n\n");

    /* 零页 */
    struct page zero_page = {
        .refcount = 1000,  /* 被大量进程共享 */
        .mapcount = 1000,
        .flags = PG_anonymous,
    };
    for (int i = 0; i < 64; i++) zero_page.data[i] = 0;

    printf("零页：\n");
    printf("  refcount = %d（被大量进程共享）\n", zero_page.refcount);
    printf("  内容全零\n\n");

    /* 进程首次访问匿名页 */
    printf("进程首次访问匿名页：\n");
    printf("  1. 触发页 fault\n");
    printf("  2. do_anonymous_page() 被调用\n");
    printf("  3. 只读访问 → 映射到零页\n");
    printf("  4. 写入访问 → COW，分配新页面\n\n");

    /* COW 后的页面 */
    struct page new_page = {
        .refcount = 1,
        .mapcount = 1,
        .flags = PG_anonymous,
    };
    sprintf(new_page.data, "进程写入的数据");

    printf("COW 后的新页面：\n");
    printf("  refcount = %d（独占）\n", new_page.refcount);
    printf("  内容: %s\n", new_page.data);

    printf("\n--- 匿名页 vs 文件页 ---\n");
    printf("匿名页:\n");
    printf("  - 没有关联文件\n");
    printf("  - 内容全零（首次访问）\n");
    printf("  - 回收时需要写入 swap\n");
    printf("  - 使用 anon_vma 管理\n\n");
    printf("文件页:\n");
    printf("  - 关联一个文件\n");
    printf("  - 内容来自文件\n");
    printf("  - 回收时可以直接丢弃（未修改）\n");
    printf("  - 使用 address_space 管理\n");

    printf("\n--- 匿名页的生命周期 ---\n");
    printf("1. 分配: do_anonymous_page()\n");
    printf("2. 使用: 进程读写\n");
    printf("3. 回收: 写入 swap 或丢弃\n");
    printf("4. 释放: 引用计数降为 0\n");

    return 0;
}
```

*原来匿名页是"无名之辈"——没有文件归属。*

## 二

林小源在研究匿名页的过程中，理解了零页的妙用。

零页是一个特殊的全局物理页，内容全零。当进程首次以只读方式访问匿名页时，内核不需要分配新页面——直接映射到零页即可。只有在写入时才分配真正的物理页（COW）。

*原来"零"也是一种"共享"。*

---

## 三

林小源在观察匿名页的过程中，理解了它与 swap 的关系。

匿名页没有文件"后援"——当内存紧张时，匿名页不能像文件页那样直接丢弃（因为可以从文件重新读取）。匿名页必须写入 swap 分区才能回收。

*原来匿名页需要 swap 作为"后援"。*

### 道藏笔记

::: tip 内核启示
**匿名页是没有关联文件的内存页面。**

匿名页的特点：
- 没有关联文件
- 内容全零（首次访问时）
- 回收时需要写入 swap
- 使用 `anon_vma` 管理

匿名页的分配（`do_anonymous_page()`）：
1. 只读访问 → 映射到零页
2. 写入访问 → 分配新页面（COW）

零页：
- 全局物理页，内容全零
- 被大量进程共享
- 只读匿名页映射到零页
- 写入时才分配真正的物理页

匿名页 vs 文件页：
- 匿名页没有文件"后援"，回收需要 swap
- 文件页有文件"后援"，可以直接丢弃

*匿名页是"无名之辈"——没有归属，但有自己的价值。*
:::
