# 第一百八十二章：无锁链表

## 一

林小源在原子操作的基础上，领悟了无锁链表的实现。

无锁链表使用 CAS 操作实现插入和删除。不需要锁，并发性能更好。

```c:playground:无锁链表 — 无锁的艺术
#include <stdio.h>
#include <stdlib.h>
#include <stdatomic.h>

/*
 * 无锁链表:
 *
 * 插入:
 *   new->next = head->next
 *   CAS(&head->next, new->next, new)
 *   如果失败，重试
 *
 * 删除:
 *   找到前驱节点
 *   CAS(&prev->next, curr, curr->next)
 *   如果失败，重试
 *
 * 优势:
 *   无锁
 *   无死锁
 *   并发性能好
 *
 * 挑战:
 *   内存回收 (ABA 问题)
 *   复杂性高
 *   调试困难
 *
 * ABA 问题:
 *   读取 A
 *   其他线程删除 A，添加 B，再添加 A
 *   CAS 成功，但链表已变化
 *
 * 解决方案:
 *   带版本号的 CAS
 *   RCU + 无锁链表
 */

/* 无锁链表节点 */
struct lockfree_node {
    int data;
    _Atomic(struct lockfree_node *) next;
};

/* 初始化 */
void node_init(struct lockfree_node *node, int data) {
    node->data = data;
    atomic_init(&node->next, NULL);
}

/* 无锁插入 */
void lockfree_insert(struct lockfree_node *head, int data) {
    struct lockfree_node *new = malloc(sizeof(struct lockfree_node));
    node_init(new, data);

    struct lockfree_node *old_next;
    do {
        old_next = atomic_load(&head->next);
        atomic_store(&new->next, old_next);
    } while (!atomic_compare_exchange_weak(&head->next, &old_next, new));
}

/* 无锁遍历 */
void lockfree_traverse(struct lockfree_node *head) {
    struct lockfree_node *curr = atomic_load(&head->next);
    while (curr) {
        printf("  %d", curr->data);
        curr = atomic_load(&curr->next);
    }
    printf("\n");
}

/* 释放链表 */
void lockfree_free(struct lockfree_node *head) {
    struct lockfree_node *curr = atomic_load(&head->next);
    while (curr) {
        struct lockfree_node *next = atomic_load(&curr->next);
        free(curr);
        curr = next;
    }
}

int main() {
    printf("=== 无锁链表 — 无锁的艺术 ===\n\n");

    struct lockfree_node head;
    node_init(&head, 0);

    printf("--- 插入 ---\n");
    lockfree_insert(&head, 3);
    lockfree_insert(&head, 2);
    lockfree_insert(&head, 1);

    printf("链表: ");
    lockfree_traverse(&head);

    printf("\n--- 无锁插入原理 ---\n");
    printf("new->next = head->next\n");
    printf("CAS(&head->next, old, new)\n\n");
    printf("如果 CAS 失败:\n");
    printf("  其他 CPU 修改了 head->next\n");
    printf("  重新读取，重试\n\n");

    printf("--- ABA 问题 ---\n");
    printf("1. 线程 1 读取 A\n");
    printf("2. 线程 2 删除 A\n");
    printf("3. 线程 2 添加 B\n");
    printf("4. 线程 2 添加 A\n");
    printf("5. 线程 1 CAS 成功\n");
    printf("   但链表已变化!\n\n");

    printf("--- 解决方案 ---\n");
    printf("1. 带版本号的 CAS:\n");
    printf("   每次修改版本号+1\n");
    printf("   CAS 比较值和版本号\n\n");
    printf("2. RCU + 无锁:\n");
    printf("   RCU 保护内存回收\n");
    printf("   无锁保证并发\n\n");

    printf("--- 优势 vs 挑战 ---\n");
    printf("优势:\n");
    printf("  无锁\n");
    printf("  无死锁\n");
    printf("  并发性能好\n\n");
    printf("挑战:\n");
    printf("  ABA 问题\n");
    printf("  复杂性高\n");
    printf("  调试困难\n");

    lockfree_free(&head);
    return 0;
}
```

*原来"无锁链表"是"并发"的"艺术"。*

## 二

林小源在研究无锁链表的过程中，理解了 ABA 问题的严重性。

ABA 问题可能导致数据结构损坏。解决方案是使用带版本号的 CAS 或结合 RCU。

*原来"ABA"是"无锁"的"陷阱"。*

---

## 三

林小源在观察无锁链表的过程中，理解了它与 RCU 的配合。

RCU 保护内存回收，无锁链表保证并发。两者结合，既安全又高效。

*原来"组合"是"力量"的"来源"。*

### 道藏笔记

::: tip 内核启示
**无锁链表使用 CAS 实现并发操作。**

插入：
- new->next = head->next
- CAS(&head->next, old, new)
- 失败则重试

ABA 问题：
- 值被改回原值
- CAS 误判成功
- 解决：版本号或 RCU

优势：
- 无锁、无死锁
- 并发性能好

挑战：
- ABA 问题
- 复杂性高

*无锁链表是艺术——无锁并发，但需谨慎。*
:::
