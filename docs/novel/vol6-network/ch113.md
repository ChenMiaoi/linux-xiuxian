# 第一百一十三章：收帆

<CultivationRealm realm="问道期" />

> **涉及内核源码：** <KernelSourceLink path="net/core/dev.c" line="__netif_receive_skb" />

## 一

林小源在网络之海边，看到船队收帆入港——数据包接收。

数据包从网卡到达内核，经过一系列处理后传递给应用程序。这个过程涉及中断处理、协议解析、sk_buff 传递。

```c:playground:数据包接收 — 收帆入港
#include <stdio.h>

/*
 * 数据包接收的路径：
 *
 *   网卡接收数据包
 *     ↓
 *   DMA 到内存
 *     ↓
 *   触发中断 (或 NAPI 轮询)
 *     ↓
 *   分配 sk_buff
 *     ↓
 *   netif_receive_skb()
 *     ↓
 *   协议栈处理
 *     ↓
 *   传递给 socket
 *
 * NAPI 接收流程：
 *   1. 网卡中断
 *   2. 禁用网卡中断
 *   3. 调度 NAPI 轮询
 *   4. 批量处理数据包
 *   5. 处理完后启用中断
 */

int main() {
    printf("=== 数据包接收 — 收帆入港 ===\n\n");

    printf("数据包接收路径:\n\n");
    printf("  网卡接收数据包\n");
    printf("    ↓\n");
    printf("  DMA 到内存\n");
    printf("    ↓\n");
    printf("  触发中断\n");
    printf("    ↓\n");
    printf("  分配 sk_buff\n");
    printf("    ↓\n");
    printf("  netif_receive_skb()\n");
    printf("    ↓\n");
    printf("  协议栈处理\n");
    printf("    ↓\n");
    printf("  传递给 socket\n\n");

    printf("--- NAPI 接收流程 ---\n");
    printf("1. 网卡中断\n");
    printf("2. 禁用网卡中断\n");
    printf("3. 调度 NAPI 轮询\n");
    printf("4. 批量处理数据包\n");
    printf("5. 处理完后启用中断\n\n");

    printf("--- 协议栈处理 ---\n");
    printf("MAC 层:\n");
    printf("  解析 MAC 头\n");
    printf("  检查目标 MAC\n\n");
    printf("IP 层:\n");
    printf("  解析 IP 头\n");
    printf("  路由查找\n");
    printf("  传递给传输层\n\n");
    printf("传输层:\n");
    printf("  TCP/UDP 处理\n");
    printf("  传递给 socket\n\n");

    printf("--- 软中断 ---\n");
    printf("NET_RX_SOFTIRQ:\n");
    printf("  网络接收软中断\n");
    printf("  处理延迟的接收工作\n\n");
    printf("NET_TX_SOFTIRQ:\n");
    printf("  网络发送软中断\n");
    printf("  处理延迟的发送工作\n");

    return 0;
}
```

*原来"收帆"是"接收"的"过程"。*

---

## 二

林小源在研究数据包接收的过程中，理解了软中断的作用。

网络接收的大部分工作在软中断中完成——而不是在硬中断中。硬中断只做最少的工作（标记数据包），软中断在稍后处理实际的协议栈逻辑。

*原来"中断"分"硬"和"软"。*

---

## 三

林小源在观察数据包接收的过程中，理解了零拷贝的优化。

传统接收需要把数据从网卡缓冲区复制到内核缓冲区，再复制到用户空间。零拷贝技术（如 DPDK）可以跳过中间步骤，直接把数据传递给用户空间。

*原来"复制"是"性能"的"瓶颈"。*

---

### 道藏笔记

::: tip 内核启示
**数据包从网卡到应用程序的路径。**

接收路径：
- 网卡 → DMA → 中断 → sk_buff → 协议栈 → socket

NAPI 接收：
- 中断触发后切换到轮询
- 批量处理数据包
- 减少中断开销

软中断：
- `NET_RX_SOFTIRQ` — 网络接收
- `NET_TX_SOFTIRQ` — 网络发送

*数据包接收是"收帆入港"——从网卡到应用程序的旅程。*
:::
