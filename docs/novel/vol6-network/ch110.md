# 第一百一十章：海图

<CultivationRealm realm="问道期" />

## 一

林小源在研究网络的过程中，发现了一个关键问题：数据包如何找到目的地？

路由是网络的核心——它决定了数据包从源到目的地的路径。路由表就像"海图"，告诉数据包该往哪里走。

```c:playground:路由 — 数据包的海图
#include <stdio.h>

/*
 * 路由的概念：
 *
 *   主机 A (192.168.1.10)
 *     ↓
 *   默认网关 (192.168.1.1)
 *     ↓
 *   路由器 (10.0.0.1)
 *     ↓
 *   主机 B (10.0.0.20)
 *
 * 路由表:
 *   目标网络        下一跳         接口
 *   192.168.1.0/24  直接          eth0
 *   10.0.0.0/8      192.168.1.1   eth0
 *   0.0.0.0/0       192.168.1.1   eth0
 *
 * IP 地址:
 *   网络部分 + 主机部分
 *   192.168.1.10/24
 *   网络: 192.168.1.0
 *   主机: 10
 *
 * 子网掩码:
 *   255.255.255.0 = /24
 *   区分网络和主机部分
 */

int main() {
    printf("=== 路由 — 数据包的海图 ===\n\n");

    printf("路由的概念:\n\n");
    printf("  主机 A (192.168.1.10)\n");
    printf("    ↓\n");
    printf("  默认网关 (192.168.1.1)\n");
    printf("    ↓\n");
    printf("  路由器 (10.0.0.1)\n");
    printf("    ↓\n");
    printf("  主机 B (10.0.0.20)\n\n");

    printf("--- 路由表 ---\n");
    printf("%-20s %-15s %-8s\n",
           "目标网络", "下一跳", "接口");
    printf("%-20s %-15s %-8s\n",
           "---", "---", "---");
    printf("%-20s %-15s %-8s\n",
           "192.168.1.0/24", "直接", "eth0");
    printf("%-20s %-15s %-8s\n",
           "10.0.0.0/8", "192.168.1.1", "eth0");
    printf("%-20s %-15s %-8s\n",
           "0.0.0.0/0", "192.168.1.1", "eth0\n");

    printf("--- IP 地址结构 ---\n");
    printf("192.168.1.10/24:\n");
    printf("  网络部分: 192.168.1.0\n");
    printf("  主机部分: 10\n");
    printf("  子网掩码: 255.255.255.0\n\n");

    printf("--- 路由查找 ---\n");
    printf("1. 查找目标 IP\n");
    printf("2. 匹配最长前缀\n");
    printf("3. 获取下一跳\n");
    printf("4. 转发数据包\n\n");

    printf("--- 查看路由 ---\n");
    printf("ip route show\n");
    printf("  default via 192.168.1.1 dev eth0\n");
    printf("  192.168.1.0/24 dev eth0\n");
    printf("  10.0.0.0/8 via 192.168.1.1\n\n");

    printf("--- 路由类型 ---\n");
    printf("直连路由: 同一子网\n");
    printf("静态路由: 手动配置\n");
    printf("动态路由: 路由协议（RIP, OSPF）\n");

    return 0;
}
```

*原来"海图"是"路径"的"指南"。*

## 二

林小源在研究路由的过程中，理解了最长前缀匹配。

当数据包的目标 IP 匹配多个路由条目时，内核选择前缀最长的那个——这叫"最长前缀匹配"。这样可以实现更精确的路由控制。

*原来"最长"是"最精确"。*

---

## 三

林小源在观察路由的过程中，理解了默认路由的作用。

默认路由（0.0.0.0/0）是"兜底"路由——当没有更具体的路由匹配时，数据包走默认路由。通常指向网关。

*原来"默认"是"最后"的"选择"。*

### 道藏笔记

::: tip 内核启示
**路由决定数据包的转发路径。**

路由表包含：
- 目标网络 — 数据包要去的地方
- 下一跳 — 转发给谁
- 接口 — 从哪个网卡发出

路由查找：
- 最长前缀匹配
- 选择最具体的路由

路由类型：
- 直连路由 — 同一子网
- 静态路由 — 手动配置
- 动态路由 — 路由协议

默认路由：
- 0.0.0.0/0 — 兜底路由
- 通常指向网关

*路由是"海图"——告诉数据包该往哪里走。*
:::
