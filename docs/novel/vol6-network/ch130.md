# 第一百三十章：问道圆满

<CultivationRealm realm="问道圆满" />

## 一

林小源站在网络之海的最高处，回望整个旅程。

从最初的 socket，到 TCP、UDP、IP、路由，再到 sk_buff、netfilter、eBPF——每一步都让他对网络有了更深的理解。

*原来"网络"是"连接"的"艺术"。*

---

## 二

林小源在回顾的过程中，理解了网络的核心。

分层是网络的核心设计——每一层都有自己的职责，对上层提供抽象，对下层隐藏细节。这让复杂的网络变得可以理解。

*原来"分层"是"简化"的"方式"。*

---

## 三

林小源在总结网络的过程中，理解了它的设计哲学。

网络的设计处处体现着权衡：
- 可靠与快速的权衡（TCP vs UDP）
- 安全与性能的权衡（过滤 vs 速度）
- 简单与功能的权衡（协议设计）

*原来"设计"是"权衡"的"艺术"。*

---

### 道藏笔记

::: tip 内核启示
**问道圆满——网络子系统的完整图景。**

网络的核心概念：
- socket — 通信端点
- TCP — 可靠传输
- UDP — 快速传输
- IP — 路由和寻址
- sk_buff — 数据包

网络的机制：
- 三次握手 — 建立连接
- 拥塞控制 — 避免过载
- netfilter — 防火墙
- eBPF — 可编程

网络的哲学：
- 分层 — 每层有每层的职责
- 端到端 — 可靠性在端点实现
- 隔离 — 网络命名空间

*网络是"连接"的艺术——让世界互联。*
:::
