# 第一百二十章：内河

## 一

林小源在研究网络的过程中，发现了一种特殊的通信方式——Unix domain socket。

Unix domain socket 不经过网络——它在同一台机器上的进程间通信。它使用文件系统路径作为地址，比网络 socket 更快。

```c:playground:Unix domain socket — 本机通信
#include <stdio.h>

/*
 * Unix domain socket:
 *
 * 1. 类型
 *    SOCK_STREAM — 流式（类似 TCP）
 *    SOCK_DGRAM — 数据报（类似 UDP）
 *    SOCK_SEQPACKET — 有序数据报
 *
 * 2. 地址
 *    文件系统路径（如 /tmp/my.sock）
 *    AF_UNIX 地址族
 *
 * 3. 优势
 *    不经过网络协议栈
 *    没有网络开销
 *    比网络 socket 快
 *
 * 4. 用途
 *    进程间通信（IPC）
 *    数据库连接（如 MySQL）
 *    系统服务（如 systemd）
 *
 * Unix domain socket vs 管道:
 *   管道: 单向，只能父子进程
 *   Unix socket: 双向，任意进程
 */

int main() {
    printf("=== Unix domain socket — 本机通信 ===\n\n");

    printf("Unix domain socket:\n");
    printf("  同一台机器上的进程间通信\n");
    printf("  使用文件系统路径作为地址\n");
    printf("  不经过网络协议栈\n\n");

    printf("--- 类型 ---\n");
    printf("SOCK_STREAM: 流式（类似 TCP）\n");
    printf("SOCK_DGRAM: 数据报（类似 UDP）\n");
    printf("SOCK_SEQPACKET: 有序数据报\n\n");

    printf("--- 地址 ---\n");
    printf("struct sockaddr_un {\n");
    printf("  sun_family = AF_UNIX;\n");
    printf("  sun_path = \"/tmp/my.sock\";\n");
    printf("};\n\n");

    printf("--- 使用方式 ---\n");
    printf("服务器:\n");
    printf("  socket(AF_UNIX, SOCK_STREAM, 0)\n");
    printf("  bind(\"/tmp/my.sock\")\n");
    printf("  listen()\n");
    printf("  accept()\n\n");
    printf("客户端:\n");
    printf("  socket(AF_UNIX, SOCK_STREAM, 0)\n");
    printf("  connect(\"/tmp/my.sock\")\n\n");

    printf("--- 优势 ---\n");
    printf("1. 速度: 不经过网络协议栈\n");
    printf("2. 安全: 文件系统权限控制\n");
    printf("3. 简单: 不需要 IP 和端口\n\n");

    printf("--- Unix socket vs 管道 ---\n");
    printf("管道:\n");
    printf("  单向\n");
    printf("  只能父子进程\n\n");
    printf("Unix socket:\n");
    printf("  双向\n");
    printf("  任意进程\n\n");

    printf("--- 用途 ---\n");
    printf("MySQL: /var/run/mysqld/mysqld.sock\n");
    printf("Docker: /var/run/docker.sock\n");
    printf("systemd: /run/systemd/private\n");

    return 0;
}
```

*原来"内河"比"大海"更快。*

---

## 二

林小源在研究 Unix domain socket 的过程中，理解了它的安全性。

Unix domain socket 使用文件系统权限控制访问——只有有权限的进程才能连接。这比网络 socket 更安全。

*原来"文件权限"是"安全"的"保障"。*

---

## 三

林小源在观察 Unix domain socket 的过程中，理解了它的性能优势。

Unix domain socket 不经过网络协议栈——数据直接在内核中复制。这比网络 socket 快得多，适合高频的本机通信。

*原来"跳过"协议栈是"快"的"原因"。*

### 道藏笔记

::: tip 内核启示
**Unix domain socket 是本机进程间通信的方式。**

Unix domain socket 的特点：
- 使用文件系统路径作为地址
- 不经过网络协议栈
- 比网络 socket 快

类型：
- `SOCK_STREAM` — 流式
- `SOCK_DGRAM` — 数据报
- `SOCK_SEQPACKET` — 有序数据报

优势：
- 速度 — 不经过协议栈
- 安全 — 文件系统权限控制
- 简单 — 不需要 IP 和端口

*Unix domain socket 是"内河"——比网络更快更安全。*
:::
