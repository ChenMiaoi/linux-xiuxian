# 第一百二十二章：选帆

## 一

林小源在研究 socket 的过程中，发现了一种调优机制——socket 选项。

socket 选项允许应用程序调整 socket 的行为——缓冲区大小、超时时间、地址重用等。

```c:playground:socket 选项 — 调优的手段
#include <stdio.h>

/*
 * 常用的 socket 选项：
 *
 * SO_REUSEADDR:
 *   允许重用本地地址
 *   服务器重启时有用
 *
 * SO_REUSEPORT:
 *   允许多个 socket 绑定同一端口
 *   负载均衡
 *
 * SO_RCVBUF / SO_SNDBUF:
 *   接收/发送缓冲区大小
 *   影响性能
 *
 * SO_RCVTIMEO / SO_SNDTIMEO:
 *   接收/发送超时
 *
 * TCP_NODELAY:
 *   禁用 Nagle 算法
 *   减少延迟
 *
 * TCP_KEEPIDLE / TCP_KEEPINTVL / TCP_KEEPCNT:
 *   TCP keepalive 参数
 */

int main() {
    printf("=== socket 选项 — 调优的手段 ===\n\n");

    printf("常用的 socket 选项:\n\n");

    printf("SO_REUSEADDR:\n");
    printf("  允许重用本地地址\n");
    printf("  服务器重启时有用\n");
    printf("  setsockopt(fd, SOL_SOCKET, SO_REUSEADDR, &opt, sizeof(opt))\n\n");

    printf("SO_REUSEPORT:\n");
    printf("  允许多个 socket 绑定同一端口\n");
    printf("  负载均衡\n\n");

    printf("SO_RCVBUF / SO_SNDBUF:\n");
    printf("  接收/发送缓冲区大小\n");
    printf("  影响吞吐量\n\n");

    printf("SO_RCVTIMEO / SO_SNDTIMEO:\n");
    printf("  接收/发送超时\n");
    printf("  避免永久阻塞\n\n");

    printf("--- TCP 选项 ---\n\n");

    printf("TCP_NODELAY:\n");
    printf("  禁用 Nagle 算法\n");
    printf("  减少延迟\n");
    printf("  适合交互式应用\n\n");

    printf("TCP_KEEPIDLE:\n");
    printf("  空闲多久后开始 keepalive\n\n");
    printf("TCP_KEEPINTVL:\n");
    printf("  keepalive 探测间隔\n\n");
    printf("TCP_KEEPCNT:\n");
    printf("  keepalive 探测次数\n\n");

    printf("--- Nagle 算法 ---\n");
    printf("Nagle 算法:\n");
    printf("  合并小数据包\n");
    printf("  减少网络开销\n");
    printf("  但增加延迟\n\n");
    printf("TCP_NODELAY:\n");
    printf("  禁用 Nagle\n");
    printf("  立即发送\n\n");

    printf("--- 查看 socket 选项 ---\n");
    printf("getsockopt(fd, SOL_SOCKET, SO_RCVBUF, &val, &len)\n");

    return 0;
}
```

*原来"选帆"是"调优"的"方式"。*

---

## 二

林小源在研究 socket 选项的过程中，理解了 Nagle 算法的作用。

Nagle 算法会合并小数据包——减少网络开销但增加延迟。对于交互式应用（如 SSH、游戏），应该禁用 Nagle 算法（TCP_NODELAY）。

*原来"合并"和"延迟"是矛盾的。*

---

## 三

林小源在观察 socket 选项的过程中，理解了缓冲区大小的影响。

接收和发送缓冲区的大小影响性能——太小会导致丢包，太大会浪费内存。应该根据应用的特点调整。

*原来"大小"影响"性能"。*

### 道藏笔记

::: tip 内核启示
**socket 选项允许调优 socket 的行为。**

常用选项：
- `SO_REUSEADDR` — 重用本地地址
- `SO_RCVBUF/SO_SNDBUF` — 缓冲区大小
- `TCP_NODELAY` — 禁用 Nagle 算法
- `TCP_KEEPIDLE` — keepalive 参数

Nagle 算法：
- 合并小数据包
- 减少网络开销
- 增加延迟
- `TCP_NODELAY` 禁用

*socket 选项是"选帆"——根据需求调整行为。*
:::
