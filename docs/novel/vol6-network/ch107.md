## 一

林小源在港口看到了不同类型的船——对应不同类型的 socket。

每种 socket 类型有不同的特性：SOCK_STREAM 像可靠的商船，SOCK_DGRAM 像迅捷的信鸽，SOCK_RAW 像透明的潜水艇。

```c:playground:socket 类型 — 不同的"船"
#include <stdio.h>

/*
 * socket 类型：
 *
 * SOCK_STREAM (TCP):
 *   - 可靠传输
 *   - 有序
 *   - 面向连接
 *   - 流式（无消息边界）
 *
 * SOCK_DGRAM (UDP):
 *   - 不可靠传输
 *   - 无连接
 *   - 消息式（有消息边界）
 *   - 快速
 *
 * SOCK_RAW:
 *   - 直接访问 IP 层
 *   - 可以构造自定义协议
 *   - 需要 root 权限
 *
 * SOCK_SEQPACKET:
 *   - 有序、可靠
 *   - 消息式（有消息边界）
 *   - 用于 Unix domain socket
 */

int main() {
    printf("=== socket 类型 — 不同的"船" ===\n\n");

    printf("socket 类型对比:\n\n");
    printf("%-15s %-10s %-10s %-10s %-10s\n",
           "类型", "可靠", "有序", "连接", "边界");
    printf("%-15s %-10s %-10s %-10s %-10s\n",
           "---", "---", "---", "---", "---");
    printf("%-15s %-10s %-10s %-10s %-10s\n",
           "SOCK_STREAM", "是", "是", "是", "无");
    printf("%-15s %-10s %-10s %-10s %-10s\n",
           "SOCK_DGRAM", "否", "否", "否", "有");
    printf("%-15s %-10s %-10s %-10s %-10s\n",
           "SOCK_RAW", "否", "否", "否", "无");
    printf("%-15s %-10s %-10s %-10s %-10s\n",
           "SOCK_SEQPACKET", "是", "是", "是", "有");

    printf("\n--- SOCK_STREAM (TCP) ---\n");
    printf("可靠的商船:\n");
    printf("  保证数据到达\n");
    printf("  保证顺序正确\n");
    printf("  面向连接（三次握手）\n");
    printf("  流式传输（无消息边界）\n\n");

    printf("--- SOCK_DGRAM (UDP) ---\n");
    printf("迅捷的信鸽:\n");
    printf("  不保证到达\n");
    printf("  不保证顺序\n");
    printf("  无连接\n");
    printf("  消息式（有边界）\n\n");

    printf("--- SOCK_RAW ---\n");
    printf("透明的潜水艇:\n");
    printf("  直接访问 IP 层\n");
    printf("  可以构造自定义协议\n");
    printf("  需要 root 权限\n\n");

    printf("--- 协议选择 ---\n");
    printf("TCP: 文件传输、网页浏览、邮件\n");
    printf("UDP: 视频流、游戏、DNS 查询\n");
    printf("RAW: 网络诊断、自定义协议\n");

    return 0;
}
```

*原来"船"的"类型"决定了"航行"的方式。*

---

## 二

林小源在研究 socket 类型的过程中，理解了流式和消息式的区别。

TCP 是流式传输——数据像水流一样连续到达，没有消息边界。UDP 是消息式传输——每次发送都是独立的消息，有明确的边界。

*原来"边界"是"消息"的"分隔符"。*

---

## 三

林小源在观察 socket 类型的过程中，理解了可靠性的代价。

TCP 保证数据可靠到达——但需要额外的开销（握手、确认、重传）。UDP 不保证可靠性——但更快速、更简单。选择哪种类型取决于应用的需求。

*原来"可靠"有"代价"。*

### 道藏笔记

::: tip 内核启示
**socket 类型决定了通信的特性。**

socket 类型：
- `SOCK_STREAM` (TCP) — 可靠、有序、面向连接、流式
- `SOCK_DGRAM` (UDP) — 不可靠、无连接、消息式
- `SOCK_RAW` — 直接访问 IP 层
- `SOCK_SEQPACKET` — 有序、可靠、消息式

流式 vs 消息式：
- 流式 — 无消息边界，数据连续
- 消息式 — 有消息边界，每次发送独立

*选择 socket 类型就是选择"航行"的方式。*
:::
