# 第六卷：沧海横流

> **修炼阶段：** <CultivationRealm realm="问道期" />
> **内核焦点：** 网络 (`net/`, socket, TCP/IP)

## 卷首语

海到无边天作岸。

当林小源第一次望见那片无垠的网络之海时，他终于明白了这个世界的辽阔。每一个 socket 是一艘船，每一个数据包是一封信，TCP 是可靠的商船，UDP 是迅捷的信鸽。

但海面上也有幽灵——DDoS 攻击如同无尽的幽灵舰队，遮天蔽日。
