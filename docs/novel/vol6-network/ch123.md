# 第一百二十三章：隔离之海

<CultivationRealm realm="问道期" />

> **涉及内核源码：** <KernelSourceLink path="net/core/net_namespace.c" />

## 一

林小源在研究网络的过程中，发现了一个重要的隔离机制——网络命名空间。

网络命名空间让每个容器有独立的网络栈——独立的 IP 地址、路由表、防火墙规则。容器之间互不影响。

```c:playground:网络命名空间 — 隔离的网络
#include <stdio.h>

/*
 * 网络命名空间:
 *
 *   命名空间 A              命名空间 B
 *   ┌──────────┐           ┌──────────┐
 *   │ eth0     │           │ eth0     │
 *   │ 10.0.1.2 │           │ 10.0.2.2 │
 *   │          │           │          │
 *   │ 路由表   │           │ 路由表   │
 *   │ iptables │           │ iptables │
 *   └──────────┘           └──────────┘
 *        ↑                       ↑
 *        └─────────┬─────────────┘
 *              veth pair
 *
 * 网络命名空间的隔离:
 *   - 独立的网络设备
 *   - 独立的 IP 地址
 *   - 独立的路由表
 *   - 独立的 iptables 规则
 *   - 独立的端口空间
 *
 * 创建网络命名空间:
 *   ip netns add ns1
 *   ip netns exec ns1 ip addr
 */

int main() {
    printf("=== 网络命名空间 — 隔离的网络 ===\n\n");

    printf("网络命名空间:\n\n");
    printf("  命名空间 A              命名空间 B\n");
    printf("  ┌──────────┐           ┌──────────┐\n");
    printf("  │ eth0     │           │ eth0     │\n");
    printf("  │ 10.0.1.2 │           │ 10.0.2.2 │\n");
    printf("  │          │           │          │\n");
    printf("  │ 路由表   │           │ 路由表   │\n");
    printf("  │ iptables │           │ iptables │\n");
    printf("  └──────────┘           └──────────┘\n\n");

    printf("--- 隔离的内容 ---\n");
    printf("独立的网络设备\n");
    printf("独立的 IP 地址\n");
    printf("独立的路由表\n");
    printf("独立的 iptables 规则\n");
    printf("独立的端口空间\n\n");

    printf("--- 创建和使用 ---\n");
    printf("创建:\n");
    printf("  ip netns add ns1\n\n");
    printf("查看:\n");
    printf("  ip netns list\n\n");
    printf("在命名空间中执行:\n");
    printf("  ip netns exec ns1 ip addr\n\n");

    printf("--- 连接命名空间 ---\n");
    printf("veth pair:\n");
    printf("  虚拟以太网对\n");
    printf("  一端在命名空间 A\n");
    printf("  另一端在命名空间 B\n\n");
    printf("创建 veth:\n");
    printf("  ip link add veth0 type veth peer name veth1\n");
    printf("  ip link set veth1 netns ns1\n\n");

    printf("--- 容器网络 ---\n");
    printf("每个容器有自己的网络命名空间:\n");
    printf("  容器 1: 10.0.1.2\n");
    printf("  容器 2: 10.0.2.2\n");
    printf("  互相隔离\n");

    return 0;
}
```

*原来"隔离"从"命名空间"开始。*

---

## 二

林小源在研究网络命名空间的过程中，理解了 veth pair 的作用。

veth pair 是连接两个命名空间的"虚拟网线"——一端在命名空间 A，另一端在命名空间 B。通过 veth pair，不同命名空间中的容器可以通信。

*原来"虚拟网线"连接"隔离"的"世界"。*

---

## 三

林小源在观察网络命名空间的过程中，理解了容器网络的基础。

每个容器有自己的网络命名空间——独立的 IP、路由、防火墙。容器之间的通信通过 veth pair 和网桥实现。

*原来"容器"的"网络"是"虚拟"的。*

### 道藏笔记

::: tip 内核启示
**网络命名空间隔离网络资源。**

网络命名空间的隔离：
- 独立的网络设备
- 独立的 IP 地址
- 独立的路由表
- 独立的 iptables 规则

连接命名空间：
- veth pair — 虚拟以太网对
- 网桥 — 连接多个命名空间

容器网络：
- 每个容器有自己的命名空间
- 通过 veth pair 和网桥通信

*网络命名空间是"隔离之海"——让容器拥有独立的网络世界。*
:::
