# 第一百七十一章：内核加密

<CultivationRealm realm="渡劫期" />

> **涉及内核源码：** <KernelSourceLink path="crypto/api.c" />

## 一

林小源在抵御了 Spectre 和 Meltdown 后，发现了内核的加密框架——crypto API。

内核需要加密来保护数据：磁盘加密、网络加密、密钥存储。crypto API 提供了统一的加密接口。

```c:playground:内核加密 — 保护数据
#include <stdio.h>
#include <string.h>

/*
 * 内核 crypto API:
 *
 * 算法类型:
 *   cipher — 对称加密 (AES, DES)
 *   hash — 哈希 (SHA256, MD5)
 *   aead — 认证加密 (GCM, CCM)
 *   skcipher — 对称分组加密
 *   akcipher — 非对称加密 (RSA)
 *   kdf — 密钥派生函数
 *
 * 使用方式:
 *   1. 分配算法
 *      crypto_alloc_skcipher("aes", 0, 0)
 *
 *   2. 设置密钥
 *      crypto_skcipher_setkey(tfm, key, keylen)
 *
 *   3. 加密/解密
 *      crypto_skcipher_encrypt(req)
 *      crypto_skcipher_decrypt(req)
 *
 * 应用场景:
 *   dm-crypt — 磁盘加密
 *   IPsec — 网络加密
 *   TLS — 传输加密
 *   dm-verity — 完整性验证
 */

/* 模拟加密算法 */
struct crypto_alg {
    const char *name;
    const char *type;
    int keysize;
    int blocksize;
};

struct crypto_alg algorithms[] = {
    {"aes", "skcipher", 16, 16},
    {"aes-256", "skcipher", 32, 16},
    {"sha256", "hash", 0, 32},
    {"hmac-sha256", "hash", 32, 32},
    {"gcm(aes)", "aead", 16, 16},
};

/* 模拟加密操作 */
void simulate_encrypt(const char *algo, const char *plaintext) {
    printf("  算法: %s\n", algo);
    printf("  明文: %s\n", plaintext);
    printf("  密文: [模拟加密结果]\n");
}

void simulate_hash(const char *algo, const char *data) {
    printf("  算法: %s\n", algo);
    printf("  数据: %s\n", data);
    printf("  哈希: [模拟哈希值]\n");
}

int main() {
    printf("=== 内核加密 — 保护数据 ===\n\n");

    printf("内核 crypto API 提供加密功能:\n\n");

    printf("--- 支持的算法 ---\n");
    int n = sizeof(algorithms) / sizeof(algorithms[0]);
    for (int i = 0; i < n; i++) {
        printf("%s:\n", algorithms[i].name);
        printf("  类型: %s\n", algorithms[i].type);
        if (algorithms[i].keysize)
            printf("  密钥长度: %d 字节\n", algorithms[i].keysize);
        printf("  块大小: %d 字节\n", algorithms[i].blocksize);
    }

    printf("\n--- 加密操作 ---\n");
    simulate_encrypt("aes-256", "Hello, World!");

    printf("\n--- 哈希操作 ---\n");
    simulate_hash("sha256", "Hello, World!");

    printf("\n--- 应用场景 ---\n");
    printf("dm-crypt (磁盘加密):\n");
    printf("  加密整个磁盘\n");
    printf("  LUKS 格式\n");
    printf("  cryptsetup luksFormat\n\n");
    printf("IPsec (网络加密):\n");
    printf("  加密网络流量\n");
    printf("  ESP/AH 协议\n\n");
    printf("TLS (传输加密):\n");
    printf("  kTLS — 内核 TLS\n");
    printf("  减少用户空间开销\n\n");
    printf("dm-verity (完整性):\n");
    printf("  验证磁盘数据\n");
    printf("  防止篡改\n\n");

    printf("--- 查看支持的算法 ---\n");
    printf("cat /proc/crypto\n");

    return 0;
}
```

*原来"crypto"是"数据"的"护盾"。*

---

## 二

林小源在研究 crypto API 的过程中，理解了它的设计。

crypto API 提供统一的接口，支持多种加密算法。算法可以是硬件加速的，也可以是软件实现的。内核自动选择最优实现。

*原来"统一接口"是"灵活"的"基础"。*

---

## 三

林小源在观察加密应用的过程中，理解了 dm-crypt 的重要性。

dm-crypt 可以加密整个磁盘。即使硬盘被盗，数据也不会泄漏。这是保护敏感数据的关键手段。

*原来"磁盘加密"是"数据安全"的"基石"。*
