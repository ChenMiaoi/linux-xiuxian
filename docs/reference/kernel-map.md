# 内核地图

Linux 内核源码的组织结构，映射到修仙世界的地理。

## 源码目录 → 修仙世界

| 目录 | 修仙世界 | 说明 |
|---|---|---|
| `arch/x86/boot/` | 混沌之源 | 启动引导代码，创世的起点 |
| `init/main.c` | 天道中枢 | `start_kernel()`，万物的开端 |
| `kernel/` | 天道法则 | 进程管理、调度器、信号等核心机制 |
| `kernel/sched/` | 调度竞技场 | CFS、RT、Deadline 调度器 |
| `mm/` | 内存宫殿 | 内存管理的所有奥秘 |
| `fs/` | 文件系统之森 | VFS 及各种文件系统实现 |
| `net/` | 网络之海 | 网络协议栈 |
| `drivers/` | 设备山脉 | 所有设备驱动 |
| `security/` | 天劫试炼场 | 安全框架和访问控制 |
| `include/` | 道藏典籍 | 头文件，内核的经书 |
| `lib/` | 工具库 | 通用工具函数 |
| `kernel/rcu/` | 无常之道 | RCU 子系统 |
| `ipc/` | 通信殿 | 进程间通信 |
| `block/` | 块设备层 | 块设备 I/O |

## 修炼路径

```
start_kernel() → 炼气期
    ├── fork() → 筑基期
    ├── sched/ → 结丹期
    ├── mm/ → 元婴期
    ├── fs/ → 斩灵期
    ├── net/ → 问道期
    ├── drivers/ → 合道期
    ├── security/ → 渡劫期
    └── RCU/无锁 → 大乘期 → 飞升
```
