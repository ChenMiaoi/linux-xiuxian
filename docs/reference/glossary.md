# 术语对照表

内核术语与修仙术语的对照。

## 基础概念

| 内核术语 | 修仙术语 | 说明 |
|---|---|---|
| Process | 修士/进程 | 内核中的执行实体 |
| PID | 修士编号 | 进程标识符 |
| `task_struct` | 修仙之躯 | 进程的全部信息 |
| Kernel Space (Ring 0) | 内核界 | 修仙正界 |
| User Space (Ring 3) | 凡人界 | 应用程序的世界 |
| System Call | 天条/祈祷 | 用户态进入内核态的唯一合法通道 |
| Interrupt | 天旨 | 不期而至的紧急信号 |
| Signal | 飞剑传书 | 进程间消息 |
| `SIGKILL` | 不可挡死刑 | 无法捕获的终止信号 |
| `SIGSEGV` | 走火入魔 | 段错误，内存访问越界 |
| Root (UID 0) | 天帝 | 最高权限 |
| Capabilities | 封号 | 细粒度权限 |
| Kernel Module | 游方修士 | 可动态加载的代码 |

## 进程管理

| 内核术语 | 修仙术语 | 说明 |
|---|---|---|
| `fork()` | 分身之术 | 创建子进程 |
| `execve()` | 变形秘术 | 替换进程镜像 |
| `exit()` | 归虚 | 进程终止 |
| `wait()` | 收尸 | 回收子进程 |
| Zombie Process | 僵尸 | 已死但未被回收的进程 |
| `swapper/0` | idle 进程 | PID 0，最底层的进程 |
| `init` / `systemd` | 天选之子 | PID 1，第一个用户进程 |

## 调度器

| 内核术语 | 修仙术语 | 说明 |
|---|---|---|
| CFS | 天道均衡 | 完全公平调度器 |
| Red-Black Tree | 红黑天秤 | CFS 的数据结构 |
| `vruntime` | 修为值 | 虚拟运行时间 |
| Time Slice | 时间片 | 分配给进程的 CPU 时间 |
| Preemption | 打断修炼 | 高优先级进程抢占 CPU |
| Load Balancing | 均衡大法 | 多核间的任务分配 |
| CPU Affinity | 亲和绑定 | 进程与 CPU 核心的绑定 |

## 内存管理

| 内核术语 | 修仙术语 | 说明 |
|---|---|---|
| Virtual Memory | 虚拟内景 | 进程看到的地址空间 |
| Page Table | 经脉 | 虚拟地址到物理地址的映射 |
| Page Fault | 触发顿悟 | 访问未映射的内存页 |
| OOM Killer | 天劫 | 内存耗尽时的杀手 |
| Slab Allocator | 精炼大师 | 高效的内核内存分配器 |
| Swap | 外渡存储 | 将内存页换出到磁盘 |
| Huge Pages | 大页灵力 | 更大的内存页 |
| Memory Leak | 走火入魔 | 内存分配后未释放 |

## 文件系统

| 内核术语 | 修仙术语 | 说明 |
|---|---|---|
| VFS | 至高抽象 | 虚拟文件系统层 |
| inode | 古树 | 文件的元数据 |
| dentry | 路标 | 目录项缓存 |
| superblock | 守护灵 | 文件系统超级块 |
| ext4 | 老树 | 传统可靠的文件系统 |
| btrfs | 新树 | 现代高级文件系统 |
| procfs | 窗户 | 观察内核状态的接口 |
| `fsck` | 净化仪式 | 文件系统检查修复 |

## 网络

| 内核术语 | 修仙术语 | 说明 |
|---|---|---|
| Socket | 造舟 | 网络通信端点 |
| TCP | 商船 | 可靠但较慢的传输协议 |
| UDP | 信鸽 | 快速但不可靠的传输协议 |
| IP Address | 坐标 | 网络地址 |
| Port | 港口 | 服务端口 |
| Netfilter | 海防 | 包过滤框架 |
| DDoS | 幽灵舰队 | 分布式拒绝服务攻击 |
